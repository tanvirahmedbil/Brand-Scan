# Project Instructions

## Auto-load: design-taste-frontend skill

Whenever you are about to design or develop a website, landing page, portfolio, web UI, or any frontend interface — **before writing any code** — automatically invoke the design-taste-frontend skill:

```
Skill({skill: "design-taste-frontend"})
```

This applies to any task that involves:
- Creating or building a website or landing page
- Designing or coding a web UI or frontend component
- Redesigning or improving an existing web project
- Writing HTML, CSS, or frontend JavaScript for a page layout

Do not wait for the user to ask. Load the skill automatically, declare the one-line Design Read, set the three dials, then proceed.
